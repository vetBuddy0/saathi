Saathi Console

How she remembers, who she is, and what she runs on.

One turn, end to end

She presses the button (or says the name) and speaks. Everything below happens for every turn; the two steps on the bottom row run after she has heard the reply, so they never slow her down.

    1. DigestOne background call turns the exchange into an episode worth remembering (with an importance score) and folds older talk into the running summary.
    2. CompilePersona + active rules + the 5 best episodes are rewritten as plain sentences, ready for the next turn. Memory is one turn stale on purpose.

    Stored vs sent

    Memory is stored as rows with scores, timestamps and sources. The model never sees a score: it receives sentences. See the exact text on the Personality tab.

            What makes up her personality

            Nothing about Saathi's character is a hidden setting. Every turn the model is given these layers, top to bottom, as plain sentences, and nothing else. Numbers (confidence, importance, scores) are stored to decide what to send; the model never sees them.

              How episodes are picked

              score = recency + importance + relevance each scaled 0–1 across all episodes, then added; the top ones are sent

              Where it is stored

              The database, table by table

              One SQLite file. Memory is only ever added or retired, never rewritten in place, so every belief keeps its history and its source.

              Persona

              The first thing the model reads every turn: who Saathi is and how she speaks. Saving writes persona.txt in the data folder, which wins over the shipped file and survives app updates. Reset goes back to the shipped one.

              What the model receives right now

              Exactly the system text compiled from the persona, the active rules ([memory N]) and the retrieved episodes, plus two sentences added by code: the memory-number instruction and the two-sentence length cap. Then come the conversation window and her words.
